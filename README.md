# オートクリッカー

Python (tkinter) で作った、座標を登録して順番にクリックするオートクリッカーです。

## 機能

- **F12キーで座標を登録**(他のウィンドウが前面にあるときも反応します)
- 登録した座標ごとに、**左クリック / 右クリック**と**クリック間隔(ミリ秒)**を設定
- 座標の**移動・変更・削除**
- **クリック回数**の指定(`0` で止めるまで続行)
- **開始時間**の指定(開始ボタンを押してから何秒後に始めるか)
- 実行中の**状態とクリック数**の表示
- **右クリックで停止**(ツールが出したクリックでは止まりません)
- メニューから**常に最前面に表示**を切り替え

## 動作環境

- Windows 10 / 11
- Python 3.x

## 必要なライブラリ

```
pip install pyautogui pynput
```

`tkinter` は Python に標準で付属しています。

## 使い方

1. このリポジトリをダウンロードし、`.py` ファイルと画像ファイルを**同じフォルダ**に置きます。
2. 次のコマンドで起動します。

   ```
   python autoclicker.py
   ```

3. クリックしたい場所にマウスを置き、**F12キー**を押して座標を登録します。
   (登録する前に、画面の「クリック間隔」と「左クリック / 右クリック」を選んでおきます)
4. 「クリック回数」と「開始時間」を設定します。
5. 「**開始**」を押すと、開始時間のあと、登録した座標を上から順に繰り返しクリックします。
6. 止めるときは、**マウスの右クリック**をします。

### 設定項目

| 項目 | 内容 |
|---|---|
| クリック間隔 | その座標をクリックしたあと、次のクリックまで待つ時間(ミリ秒) |
| 左クリック / 右クリック | 登録するときのクリックの種類 |
| クリック回数 | 合計のクリック回数。`0` の場合は止めるまで続けます |
| 開始時間 | 「開始」を押してから実行を始めるまでの時間(秒) |

## 注意点

- 座標は、**登録したときの画面の状態**を基準にします。ウィンドウの位置や、画面の拡大率(Windowsの「拡大縮小」)を変えると、ずれることがあります。
- ゲームなどが**管理者権限**で動いている場合、このツールも管理者として起動しないと、クリックやF12が届かないことがあります。
- 一覧に**右クリック**の座標を入れていても、ツール自身が出した右クリックでは止まりません。人が行った右クリックだけが停止の合図になります。
- 動作確認をするときは、まず**クリック回数を小さな値**にして、自分のアプリの「終了」ボタンなどの上を**座標に登録しない**ようにしてください。
- メニューの「設定の保存」「設定の読み込み」は、まだ実装していません。
